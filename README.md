# Onyx landing page

The site for **Onyx: Fitness & AI Coach**, live at https://onyxcoach.app (GitHub Pages; the github.io address redirects there)

- `index.html` is the page; `privacy.html` is the privacy policy.
- `assets/site.css` and `assets/site.js` hold the styles and the interactive pieces (readiness ring, Coach chat, run map, biological-age gauge and so on).
- Every interactive example uses illustrative data.
- `assets/og.png` is the preview image shown when the link is shared.
